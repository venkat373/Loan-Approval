# 🏦 Loan Approval Prediction using Machine Learning

A machine learning project that predicts whether a loan application will be **Approved** or **Rejected** based on applicant financial and demographic details. This project demonstrates **data preprocessing, exploratory data analysis (EDA), feature engineering, model building, and evaluation** using Python.

---

## 📌 Project Overview

Financial institutions receive thousands of loan applications every day. Manually evaluating applications is time-consuming and may lead to inconsistent decisions.

This project aims to build a **Loan Approval Prediction System** that can assist banks and financial organizations in making **faster and data-driven lending decisions**.

---

## 🎯 Objectives

- Analyze loan applicant data
- Clean and preprocess missing or inconsistent values
- Perform exploratory data analysis (EDA)
- Build machine learning classification models
- Evaluate model performance using appropriate metrics
- Predict loan approval status for new applicants

---

## 📂 Dataset Features

The dataset contains attributes such as:

- Number of Dependents
- Education
- Self Employed Status
- Annual Income
- Loan Amount
- Loan Term
- CIBIL Score
- Residential Assets Value
- Commercial Assets Value
- Luxury Assets Value
- Bank Asset Value
- Loan Status (Target Variable)
